# Architecture Assets

This directory contains the current architecture diagrams for the system.

## Files

- `architecture-overview.png`: exported high-level overview image
- `high-level-application-architecture.drawio`: editable source for the main system layout
- `service-discovery-and-interaction.drawio`: editable source for service discovery and request flow
- `service-discovery-and-interaction.png`: exported request-flow diagram
- `security-trust-boundaries.drawio`: editable source for trust boundaries and token flow
- `security-trust-boundaries.png`: exported security diagram
- `resilience-fault-handling.drawio`: editable source for fallback and recovery behavior
- `resilience-fault-handling.png`: exported resilience diagram

## Notes

- The `.drawio` files are the editable sources.
- The `.png` files are exported views that are easier to browse quickly.
- Open the `.drawio` files in diagrams.net or draw.io when you need to update the diagrams.
