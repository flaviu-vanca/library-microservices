# Architecture Assets

This directory contains the current architecture diagrams for the system.

## Directory Structure

```
architecture/
├── drawio/                                       # Editable source files
│   ├── high-level-application-architecture.drawio
│   ├── service-discovery-and-interaction.drawio
│   ├── security-trust-boundaries.drawio
│   └── resilience-fault-handling.drawio
└── img/                                          # Exported PNG diagrams
    ├── architecture-overview.png
    ├── service-discovery-and-interaction.png
    ├── security-trust-boundaries.png
    └── resilience-fault-handling.png
```

## Notes

- The `.drawio` files in `drawio/` are the editable sources.
- The `.png` files in `img/` are exported views that are easier to browse quickly.
- Open the `.drawio` files in [diagrams.net](https://www.diagrams.net/) (draw.io) when you need to update the diagrams.
