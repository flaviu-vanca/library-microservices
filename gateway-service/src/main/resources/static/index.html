Authentication

Member login or signup

Or continue with Google, GitHub, or Facebook. Configured providers are clickable; the rest need client IDs and secrets first.

Local passwords are stored as BCrypt hashes. For Google, GitHub, or Facebook OAuth, the provider password would not be stored in this database.
